# oil-well-selection
 Selección de 200 pozos petroleros óptimos usando regresión lineal y bootstrapping
Proyecto de selección de sitios de inversión bajo incertidumbre. Usando regresión lineal y bootstrapping se identificaron los 200 pozos con mayor potencial en 3 regiones geográficas, cuantificando el riesgo de pérdida para la toma de decisiones.
Herramientas: Python · Pandas · Scikit-learn · Bootstrapping · Validación cruzada
